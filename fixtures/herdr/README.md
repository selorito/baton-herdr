# herdr reference data

Generated by `just fixtures-herdr` (`tools/capture/capture.py herdr-ref`) from
herdr 0.9.1 (stable, released 2026-09-16). Home directory paths are masked to `~`;
nothing else is changed.

| File | Source |
|------|--------|
| `api-schema-<version>.json` | `herdr api schema --json` (socket protocol 22, schema version 1) |
| `agent-manifests-<version>.json` | `herdr server agent-manifests --json`: active detection manifest per agent |
| `agent-detection/<agent>-<manifest-version>.toml` | the active manifest file for each agent coban supports |

The active detection manifests are **not** the ones bundled in the herdr binary.
herdr downloads a remote catalog (`https://herdr.dev/agent-detection/index.toml`,
see herdr `src/detect/manifest_update.rs`) into `~/.local/state/herdr/agent-detection/remote/`
and prefers it over the bundled copy. On 2026-09-24 the four files here were
byte-identical to `distribution/agent-detection/<agent>.toml` on herdr `master`.

Regenerate after upgrading herdr or when the catalog changes:

    just fixtures-herdr                          # default session
    just fixtures-herdr --herdr-session NAME     # a named session
