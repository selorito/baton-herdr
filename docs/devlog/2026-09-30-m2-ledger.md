# 2026-09-30: M2 ledger

- `ledger/store.py`: `SqliteEventStore` on SQLAlchemy 2.1 async + aiosqlite. Writes run in
  `BEGIN IMMEDIATE` transactions, so "read last seq, insert" is atomic and positions stay
  contiguous; reads use autocommit and do not take the write lock. WAL mode.
- `ledger/migrations/`: Alembic, run programmatically by `open_event_store`. Revision 0001
  creates `events` and two triggers that make the table append-only at the database level.
- `core`: `DuplicateEventError` added to the `EventStore` contract (fake updated).
- `tests/integration/test_event_store_contract.py` runs the same contract against the
  in-memory fake and SQLite, including a race of eight appends with the same `expected_seq`.
- New import-linter contract: only `coban.ledger` may import database libraries.

Next: `herdr` client (socket API: pane/agent reads, prompt, wait, event subscription) behind a
protocol in `core`, with a fake, tested against `fixtures/herdr/` and the recorded events.
