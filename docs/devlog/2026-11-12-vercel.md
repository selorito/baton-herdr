# 2026-11-12: delivered pages on Vercel; long prompts on WSL1

- On kasa (WSL1) every project step crashed: Claude Code and its shell ended the moment the
  step's ~5 KB instructions were pasted. Measured through herdr: 4000 bytes pass, 4500 do
  not; `cat` in the same pane survives any size. WSL1 hangs the pty up on a large write to
  a raw-mode reader. The fallback now pastes in 2 KiB pieces; Claude joins them into one
  prompt ("PINEAPPLE 200" test). ADR 0022 updated.
- The operator demonstrates baton to companies by having a site built on the spot, and
  needs a link that opens on any phone. ADR 0023: `[projects] publish = "vercel"` deploys a
  delivered page through Vercel's REST API (no Node on kasa), off by default.
