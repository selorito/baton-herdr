# 2026-09-24: M0 skeleton

Set up the repository skeleton. No business logic.

- Python 3.12 package under `src/coban/`, managed with uv. Empty packages for every planned
  module. `coban version` CLI command.
- `core/config.py`: layered settings (init > env > `.env` > TOML > defaults), nested sections,
  secrets as `SecretStr`.
- `resolve_herdr_socket_path()`: pure function that finds the herdr socket the way herdr
  does (`HERDR_SOCKET_PATH`, `HERDR_SESSION`, XDG config dir), below an explicit
  `[herdr].socket_path` / `[herdr].session` from coban's config.
- `core/logging.py`: structlog JSON output, `log_context(task_id=..., attempt_id=...)`.
- import-linter contracts for the layer rules, passing on the empty packages.
- Rust workspace with `coban-detect` (clap, `--version` only).
- `just check` and GitHub Actions CI running the same steps.
- ADRs 0001–0003.
